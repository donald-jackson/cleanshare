# Support

Need help with CleanShare? Here is where to go.

## Bugs

If something is broken, please open an [issue](../../issues). Include your iOS
version, device model, and clear steps to reproduce.

## Questions

For usage questions, feature ideas, or general discussion, use
[Discussions](../../discussions) rather than the issue tracker.

## Security

**Do not report security vulnerabilities through public issues or discussions.**
Follow the responsible-disclosure process in [`SECURITY.md`](SECURITY.md)
instead.
