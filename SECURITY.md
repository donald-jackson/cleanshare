# Security Policy

CleanShare is a privacy tool. We treat security and privacy bugs with the
highest priority, and we ask that you report them responsibly.

## Supported Versions

Only the latest released version receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

**Do not file public issues or discussions for security or privacy bugs.**
Public disclosure before a fix is available puts users at risk.

Instead, report privately through GitHub Security Advisories:

- Open a new advisory at
  `https://github.com/<placeholder>/cleanshare/security/advisories/new`

Please include:

- A clear description of the issue and its impact.
- Steps to reproduce, or a proof of concept if you have one.
- The CleanShare version, iOS version, and device model.
- Whether the issue results in metadata leaking from a "cleaned" file — this is
  the most severe class of bug for this project and is triaged first.

## What to Expect

- We aim to acknowledge a report within 7 days.
- We will keep you updated as we investigate and prepare a fix.
- With your consent, we will credit you in the release notes once the fix ships.

Thank you for helping keep CleanShare users safe.
